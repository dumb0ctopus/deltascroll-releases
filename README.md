# DeltaScroll Releases

This repository contains the public release files for DeltaScroll.

DeltaScroll is an EPUB reader for Windows. It provides local library management, reading position storage, shelves, favourites, highlights, bookmarks, notes, and backup tools.

The Windows version includes offline Piper text-to-speech.

This repository contains release files only. It does not contain the application source code.

## Download

Open the [latest release](../../releases/latest).

Download:

`DeltaScroll-windows-x64-setup.exe`

This installer is for 64-bit Windows.

## Installation

1. Download the Windows installer.
2. Run the installer.
3. Follow the installation instructions.
4. Start DeltaScroll from the Start menu or desktop shortcut.

## Included features

- EPUB library management.
- Reading position storage.
- Shelves and favourites.
- Highlights, bookmarks, and notes.
- Local backup and restore.
- Optional Google Drive backup.
- EPUB import.
- Gutenberg book import.
- Offline Piper text-to-speech.
- Three English Piper voices.

## Backup information

Backup files are unencrypted ZIP files. They can contain books, notes, highlights, bookmarks, and reading data.

Store backup files in a secure location.

## Release files

Each release contains the installer and release notes for one version of DeltaScroll.
